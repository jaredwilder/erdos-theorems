The program develops several interacting structural theories:

- extremal type tensors;
- mixing and spider structure;
- chromatic escape;
- induced-path contact codes;
- contamination/fan calculus;
- three-way recursive structure;
- cross-theorems connecting the #738 and #595 structural programs.

The individual files preserve theorem, target, finite verification, cross-problem implication and semantic-review status separately. A “proved in packet” label is not automatically a historical-novelty claim or a kernel certificate.
